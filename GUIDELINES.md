# Побажання щодо вибору моделей

Для ефективної роботи над проектом **OrderHub**, просимо дотримуватися наступних рекомендацій при виборі AI-моделі для виконання задач:

## 🚀 Gemini 3 Flash (або аналоги)
**Для простих задач:**
- Створення UI-компонентів (boilerplate, стилізація).
- Написання тестів.
- Виправлення дрібних помилок (typos, syntax).
- Генерація документації.
- CRUD операції з простими моделями.

## 🧠 Opus 4.6 (або Gemini 1.5 Pro)
**Для складних задач:**
- Архітектурні рішення (проектування БД, сервісних шарів).
- Складна бізнес-логіка (валідація статусів, парсинг CSV).
- Зовнішні інтеграції (Nova Poshta API, Shopify Sync).
- Реалізація MCP сервера.
- Масштабний рефакторинг коду.

---
> [!TIP]
> Кожна задача в `implementation_plan.md` має відмітку складність: **[Проста]** або **[Складна]**. Будь ласка, орієнтуйтеся на ці мітки.
